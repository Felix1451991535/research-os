# Fixtures (SYNTHETIC)

`golden.json`: frozen reference values, generated by `scripts/make_golden.py` (which never imports the plugin).
- Inputs are SYNTHETIC: hand-written count tables and p-values, and a seeded (`numpy.random.default_rng(20261012)`)
  synthetic ROC sample of 60 cases with rounded (tied) scores. No real patient or study data.
- Expected values come from statsmodels 0.15.0 / scipy 1.17.1 (`_generated_with` records versions). DeLong
  variance/covariance and log-method LR intervals come from a direct-definition implementation in the script.
- Regenerate with `pip install -e ".[golden]" && python scripts/make_golden.py`. Tests require relative error <= 1e-9.
